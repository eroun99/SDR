# SDR 기능 정의서 (초안)

기본 수신 기능과 확장 후보를 정리한 초안입니다. EXT 항목은 확장 후보입니다.

## 기능

| ID | 기능 | 상세 내용 |
| --- | --- | --- |
| RX-01 | 수신 설정 | PC에서 수신 입력, 중심 주파수, 샘플률, 수신 대역폭, 이득을 설정하고 적용 값을 확인한다. |
| RX-02 | I/Q 수신 | 보드에서 RF 신호를 수신해 I/Q 데이터를 PC로 전송한다. 수신 시작과 정지를 지원하고, 여러 입력을 사용하면 입력별 데이터를 구분한다. |
| RX-03 | 스펙트럼 표시 | PC에서 FFT 스펙트럼과 워터폴을 표시해 수신 신호의 주파수 분포와 시간에 따른 변화를 확인한다. |
| RX-04 | I/Q 저장 | 수신 I/Q를 파일로 저장한다. 입력 구분, 데이터 형식, 중심 주파수, 샘플률 등 재분석에 필요한 설정을 함께 기록한다. |
| RX-05 | 상태, 오류 표시 | 보드 연결 상태, 수신 상태, 수신 데이터율과 오류를 표시한다. 데이터 누락은 검출 가능한 경우 결과를 표시하고, 확인할 수 없으면 미확인으로 표시한다. |
| RX-06 | 신호 선택 | 수신 대역에서 원하는 신호의 주파수와 대역폭을 선택한다. 주파수 이동, 필터링, 샘플률 변환으로 복조에 사용할 I/Q를 추출한다. |
| RX-07 | 복조, 출력 | 선택한 신호를 지정한 변조 방식으로 PC에서 복조한다. 복조 결과를 오디오로 재생하거나 데이터로 표시, 저장한다. |
| RX-08 | 저장 데이터 재생 | 저장한 I/Q와 수신 설정을 읽어 보드 연결 없이 스펙트럼 분석과 복조를 다시 수행한다. |
| EXT-01 | 다중 신호 동시 처리 | 하나의 RF 입력에서 여러 주파수의 신호를 동시에 추출하고, 채널별로 복조하거나 저장한다. |
| EXT-02 | 신호 자동 검출 | 관측 대역에서 설정한 검출 조건을 만족하는 신호를 찾아 주파수, 검출 시각, 크기와 대역폭을 기록한다. |
| EXT-03 | 방향탐지, 빔포밍 | 여러 안테나의 I/Q를 동시에 수신하고 샘플 정렬, 위상과 이득 보정을 수행한다. 도래 방향을 추정하거나 지정한 방향의 신호를 강조하는 합성 출력을 생성한다. |
| EXT-04 | 송신 | 생성하거나 파일에서 읽은 I/Q를 보드로 전달해 RF 신호로 출력한다. 송신 시작과 정지, 중심 주파수, 샘플률, 대역폭과 출력 수준 설정을 지원한다. |

## PC SW 스펙 (초기 목표)

아직 구현 전인 목표입니다. 우선 보드 연결과 I/Q 수신·확인에 집중하고, 복조 등은 이후 단계에서 구체화합니다. 실행 환경과 보드 인터페이스는 실제 연결 시험 후 확정합니다.

| 단계 | 목표 | 확인할 사항 |
| --- | --- | --- |
| 1. 연결·수신 | PC에서 보드에 연결하고 수신 설정, 시작·정지를 제어한다. 입력별 I/Q를 받아 상태와 오류를 확인한다. | 사용할 PC 환경(MATLAB 또는 Python), 연결 방식, 수신 포맷과 실제 적용 설정 |
| 2. 확인·저장 | I/Q 파형과 FFT 스펙트럼을 보고, 원본 I/Q와 설정을 저장해 다시 읽는다. | 파일 형식, 입력 구분, 샘플률과 저장·재생 결과 |
| 3. 신호 처리 | 신호 하나를 선택해 추출·복조한다. 필요하면 오디오 재생 또는 데이터 출력과 워터폴을 추가한다. | 대상 변조 방식과 기준 시험 데이터 |

초기 수신 조건은 FW 스펙의 입력당 5 MS/s, 2 RX를 목표로 하되 실제 지원 여부와 지속 처리량은 시험으로 확인합니다. 위 단계별 구현 결과와 시험 조건을 기록하고, 검증 전 항목은 완료로 표시하지 않습니다. EXT 기능은 초기 범위에서 제외합니다.
